# GRA Unity v0.4.0 — Legacy Core + Visual Foundation

This branch is the persistent production branch for the Unity rebuild of GRA.

## Locked visual direction
- 3D voxel/block diorama world
- lush saturated greenery, layered cliffs, rivers and waterfalls
- soft cinematic/mobile-friendly lighting and depth
- dark charcoal/blue framed UI with gold, cyan, violet and green semantic accents
- the approved reference board represents MULTIPLE SEPARATE SCREENS, not one overloaded screen
- primary screens: World, Buildings, Heroes, Research, Missions, Shop, Empire/Prestige, Achievements, Settings

## Current milestone scope
- persistent shared game state
- tap/combo foundation
- building/world progression
- hero DPS
- missions
- prestige
- separate screen routing
- voxel world presentation foundation
- Unity Editor bootstrap for scene generation and Android build

## Important
Earlier WebView prototypes are rejected as production foundations. Unity is the production path from v0.4.0 onward.
