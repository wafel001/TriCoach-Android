# Pixel Empire Clicker 1.0

Pierwsza pełna wersja natywnej gry clicker/idle na Androida.

## Funkcje
- klikanie, combo i trafienia krytyczne,
- 9 ulepszeń (klik + automatyczny dochód),
- rozwijające się pixelowe miasto,
- zapis automatyczny i dochód offline do 12 h,
- osiągnięcia i klejnoty,
- system prestige (Rdzenie Imperium),
- codzienna nagroda i streak,
- losowe wydarzenia,
- boostery czasowe,
- statystyki, ustawienia, dźwięk i wibracje,
- samouczek pierwszego uruchomienia,
- obsługa bardzo dużych liczb.

## Build
Projekt używa Android Gradle Plugin i nie ma zależności runtime poza Android SDK.

```bash
gradle :app:assembleDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`
