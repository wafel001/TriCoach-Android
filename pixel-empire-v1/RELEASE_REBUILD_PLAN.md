# Pixel Empire release rebuild

Target visual reference: the polished voxel/pixel mobile-game mockup supplied in chat.

Release goals:
- dynamic voxel-style world scene occupying most of the screen
- dense game HUD: currencies, era progress, left daily/mission/achievement rail, right active events/boosters
- slow combo: x1.1 after 50 taps, +0.1 every next 50 taps
- offline income: 20% of current base CPS, capped at 12 hours
- build/shop, heroes, tech tree, missions, achievements, prestige, daily rewards, events, statistics, settings
- whole world scene tappable
- Android 9+ smoke tests and Android 15 interactive tests
- release AAB and APK pipeline

This branch is the source of truth for the Google Play candidate.
